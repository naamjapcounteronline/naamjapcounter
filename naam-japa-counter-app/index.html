Install as an app on Android (Chrome)

  1. Open naamjapcounter.online in Chrome.
  2. Tap the menu (⋮) in the top right.
  3. Choose Install app or Add to Home screen.
  4. Confirm. The Naam Jap Counter icon appears on your home screen.

Install on iPhone and iPad (Safari)

  1. Open this website in Safari.
  2. Tap the Share button.
  3. Choose Add to Home Screen.
  4. Tap Add.

Install on a computer

In Chrome or Edge, click the install icon in the address bar or choose menu → Install Naam Jap Counter. The counter then opens in its own window.

Why a web app can be better than a store app

  • No download size or permissions beyond what the browser needs.
  • Always up to date. New mantras and tools appear automatically.
  • Privacy: your counts stay in your browser; there is no account.
  • Works on every device with a modern browser.

Tips for using it on a phone

  • Turn on vibration and Keep screen on in the settings panel.
  • Use Focus mode for a distraction-free screen.
  • Set your phone to Do Not Disturb during japa.
  • Use the volume-low setting if you chant in a shared room.

Data is stored per browser, so counts on your phone and laptop are separate.
